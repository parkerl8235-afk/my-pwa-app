# Latoya's Gardening Master Plan PWA

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `garden-master-plan`.
2. Upload all five app files from this package to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, and click **Save**.
6. When deployment finishes, open the Pages URL on the phone.
7. Android/Chrome: use **Install app**. iPhone/Safari: tap **Share > Add to Home Screen**.

## Important
Planting records are stored in that browser on that device. Use the app's **Backup** tab to export a JSON backup regularly.

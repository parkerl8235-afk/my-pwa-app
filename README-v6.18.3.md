# V6.18.3 Task Generation

After Start This Planting creates an active batch, the app generates a duplicate-safe care task set linked to PlanID and plantingId. Indoor starts receive germination, growth, pot-up, hardening, and transplant tasks. Direct-sown crops receive emergence, spacing, support where relevant, and harvest checks. Slips/sets/planted batches receive establishment, growth, support/feeding where relevant, and harvest checks. A summary modal lists generated dates and opens Task Center.
